# Сайт mouren

Одностраничный сайт продукта mouren — ежедневного комплекса с коллагеном для женщин.
Чистые HTML, CSS и JavaScript: без сборки, фреймворков и зависимостей.

```
mouren/
├── index.html            — вся страница и тексты
├── favicon.svg
└── assets/
    ├── css/styles.css    — оформление, светлая и тёмная темы
    ├── js/config.js      — настройки: цены, контакты, приём заказов, юрданные
    ├── js/main.js        — поведение: тарифы, курс на 30 дней, форма заказа
    └── img/              — упаковка без фона, OG-картинка, логотип
```

## Как посмотреть локально

```bash
cd mouren
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Что настроить перед запуском

Все настройки — в `assets/js/config.js`. Пустая строка означает «не показывать».

1. **Приём заказов** — `order.endpoint`. Это адрес, который принимает POST-запрос с JSON заявки:
   форма Formspree, вебхук amoCRM или Bitrix24, сценарий Make/Zapier или ваш сервер.
   Пока адрес пустой, форма собирает текст заявки и предлагает отправить его через контакты.
   Для настоящей подписки с автосписаниями нужна платёжная система с рекуррентными платежами
   (ЮKassa, CloudPayments, Т-Касса) — её виджет подключается вместо или после формы.
2. **Контакты** — `contacts.email`, `contacts.phone`, `contacts.telegram`.
3. **Юридические данные** — `legal`: номер СГР, изготовитель, продавец (наименование, ИНН, ОГРН, адрес),
   ссылки на оферту, политику обработки персональных данных и условия подписки.
4. **Цены** — `plans`. Цена в день и экономия на 3 месяцах считаются сами.
   Цены в разметке `index.html` — запасной вариант на случай, если скрипт не загрузится;
   при смене цен поправьте их и в JSON-LD в `<head>`.
5. **Яндекс Метрика** — `analytics.yandexMetrikaId`.

## Что проверить у юриста и по документам

- **Состав и дозировки** взяты из рабочего наброска. Перед публикацией сверьте их с финальной рецептурой,
  этикеткой и свидетельством о государственной регистрации (СГР).
- **Тексты о действии веществ** («нужен для синтеза коллагена», «помогает направлять кальций в кости» и т. п.)
  допустимы, только если не выходят за рамки СГР. Реклама БАД не может создавать впечатление,
  что это лекарство или что оно лечит (38-ФЗ «О рекламе», ст. 25).
- **Предупреждение «Не является лекарственным средством»** на первом экране и в блоке тарифов
  занимает не меньше 10 % площади блока — это требование ст. 25 ч. 1.1 для рекламы в интернете.
  Высоту полосы подгоняет скрипт; не уменьшайте и не убирайте её.
- **Сравнение «22 добавки за 15 450 ₽»** — это сравнительная реклама. Сохраните расчёт по ценам маркетплейсов,
  чтобы подтвердить цифры.
- **Гарантия возврата, бесплатная доставка, личный кабинет, чек-лист анализов, протокол анализа партии,
  консультация нутрициолога** — сайт обещает всё это покупателю. Обещания должны совпадать с офертой.
- **Отзывы, рейтинги, мнения врачей и результаты наблюдений** на сайт не добавлены:
  до старта продаж их нет, а в рекламе БАД отзывы и благодарности покупателей запрещены.
- **Шрифты** подключены с Google Fonts. Чтобы IP посетителей не уходили за рубеж (152-ФЗ),
  скачайте файлы Onest и Ysabeau в `assets/fonts/` и подключите их через `@font-face`.
- **OG-картинка** указана относительным путём. Когда появится домен, замените `content="assets/img/og-image.jpg"`
  на полный адрес, иначе соцсети её не подхватят.

## Как опубликовать

Подходит любой статический хостинг: Netlify, Vercel, GitHub Pages, Яндекс Object Storage, Selectel.
Загрузите содержимое папки `mouren/` в корень сайта.
