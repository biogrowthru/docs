# Сайт mouren

Лендинг ежедневного комплекса mouren. Визуальный язык — из наброска владельца в Claude Design
(Golos Text, бордо #471D1F и пудра #F4D1CB), продающая логика — по Хормози и по разбору AG1 и IM8.

Стек: React 18, Vite, Tailwind CSS 4, Motion. Без бэкенда — собирается в статические файлы.

## Запуск

```bash
cd mouren
npm install
npm run dev      # разработка: http://localhost:5173
npm run build    # готовый сайт в mouren/dist — его и загружаем на хостинг
```

## Что где менять

- `src/config.js` — цены и тарифы, бонусы стека ценности, контакты, юрданные,
  адрес приёма заказов (`orderEndpoint`).
- `src/productData.js` — состав (31 позиция) и 10 направлений.
- `src/proofData.js` — врачи, отзывы, результаты наблюдения «Сколково».
- `src/sections/*.jsx` — тексты секций.

## Ссылки для блогеров

- `?promo=КОД` — промокод в верхней плашке и в форме заказа.
- `?angle=hair|belly|energy|pms|skin|sleep` — заголовок первого экрана под тему блогера.

## Что подтвердить перед запуском

Новые обещания оффера: консультация нутрициолога (оценена в 4 500 ₽), карта анализов (990 ₽),
дневник 12 недель в Telegram (1 490 ₽), стартовый набор (1 990 ₽), протокол мягкого старта, паспорт партии,
«цена не вырастет, пока вы с нами», гарантия результата на любой заказ, напоминание за 3 дня до списания.
Расчёт «22 добавки — 15 450 ₽» и состав сверить с этикеткой и СГР. Тексты — показать юристу (38-ФЗ, ст. 25).

## Мобильная версия

Сайт свёрстан от телефона (390 px). На телефоне: шапка уезжает при прокрутке вниз, меню — по кнопке
справа, нижняя панель «Оформить» прячется на тарифах, в финале и в подвале, состав свёрнут.
На карточке товара цена видна на первом экране, панель покупки — пока главная кнопка вне экрана.
