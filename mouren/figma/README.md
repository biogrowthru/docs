# Макет сайта в Figma

`mouren-figma-plugin/` — плагин Figma, который строит весь дизайн сайта редактируемыми слоями
(инструкция — в `mouren-figma-plugin/КАК-ЗАПУСТИТЬ.txt`).

Плагин собирается из живого сайта, поэтому после правок вёрстки его легко пересобрать:

```bash
cd mouren
npm run build                 # свежая сборка сайта в dist/
node figma/capture.mjs        # снимает экраны в figma/data.json (нужен Playwright с Chromium)
python3 figma/build.py        # собирает figma/mouren-figma-plugin/code.js (нужен Pillow)
```

- `serialize.js` — переводит отрисованную страницу в дерево слоёв: рамки, тексты с начертаниями,
  картинки, SVG-иконки; повёрнутые значки и системные чекбоксы — растром.
- `capture.mjs` — список экранов (мобайл, десктоп, состояния) и съёмка; шрифт Golos Text берётся из `fonts/`.
- `plugin-src.js` — код плагина: страницы, переменные цветов, стили текста, компоненты.
