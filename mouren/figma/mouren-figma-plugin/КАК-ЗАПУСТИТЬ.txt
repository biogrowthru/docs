mouren — макет сайта в Figma
============================

Плагин сам построит в открытом файле Figma весь дизайн сайта редактируемыми слоями:

  📱 Мобайл — лендинг и карточка товара (390 px), открытое меню, экран при прокрутке
             с нижней панелью, оформление заказа
  🖥 Десктоп — лендинг и карточка товара (1440 px)
  🎨 Дизайн-система — цвета (переменные), стили текста, компоненты:
             шапка, кнопки, чип, отзыв, вопрос, переключатель подписки, нижние панели

Как запустить (1 минута)
1. Плагины из файла работают только в приложении Figma для компьютера:
   https://www.figma.com/downloads/
2. Распакуйте этот архив в любую папку.
3. Откройте в приложении файл «mouren — сайт»:
   https://www.figma.com/design/ahTid9JFkC5eLiOoPzebbZ
4. Меню Figma (значок слева вверху) → Plugins → Development → Import plugin from manifest…
   и выберите файл manifest.json из распакованной папки.
5. Снова Menu → Plugins → Development → «mouren — макет сайта».
   Подождите около минуты — внизу появится «mouren: готово».

Повторный запуск создаст новые страницы рядом, старые не трогает.
Шрифт — Golos Text (есть в Figma из Google Fonts). Фото упаковки встроены в плагин.
